## 📖 About

Smart Health Watch is a graduation project that bridges software and hardware into a complete IoT health monitoring solution. The system consists of a custom-built wearable device and a Flutter mobile app that work together to monitor elderly patients' vital signs and detect emergencies in real time.

> 🎓 Graduation Project — IPU Private University, Aleppo, Syria

---

## 🎯 Problem Being Solved

Elderly individuals living alone face serious risks from sudden health events such as cardiac episodes or unexpected falls. This project provides a real-time monitoring solution that alerts caregivers and family members instantly when an emergency is detected.

---

## ✨ Features

### ⌚ Wearable Device (Hardware)
- Real-time heart rate monitoring
- Sudden fall detection
- Continuous vital signs tracking
- Emergency alert triggering

### 📱 Flutter Companion App
- Live vital signs dashboard
- Fall detection alerts and notifications
- Patient monitoring interface
- Health data history and trends
